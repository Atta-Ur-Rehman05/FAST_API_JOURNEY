## 🏗 Projects

### 📝 Blog API Project
A RESTful blog API with authentication, CRUD operations, pagination, and PostgreSQL integration.
- Path: `blog_api_project/`

### 🛒 E-commerce API
A production-style e-commerce backend with products, cart, checkout, orders, payments, reviews, wishlist, inventory, addresses, and Alembic migrations.
- Path: `E-commerce-api/BACKEND/`

### ✅ Task Management Full-Stack
A full-stack task management system with JWT auth, task CRUD, search, filters, pagination, and a React dashboard.
- Path: `TASK_MANAG_FULLSTACK_P/`

### 🌤️ Weather API Full-Stack
A full-stack weather application integrating a third-party weather API with a React frontend.
- Path: `weather_api_fullstack_p/`

### 🧪 Docker Test App
A small FastAPI app containerized with Docker and MongoDB setup.
- Path: `testapp_docker/`
